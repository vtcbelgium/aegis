How Aegis works in 30 seconds

1. Guard checks actions before they run
Every shell command, file write, and URL passes through deterministic offline rules. Safe work runs automatically; dangerous commands pause for you or get blocked.
2. Detective checks claims after an agent replies
Clan Lynceus compares what an AI claims ("all tests passed") against real recorded tool runs and git diffs, catching phantom test runs, ghost files, and tampered test suites.
3. Tekton manages your local and remote machines
When Tekton is installed, the Tekton tab displays your live fleet nodes, workspace allowlist, and pending approvals under the same Aegis policy floor.

What each verdict means

PASSAllowed automatically and logged in the SHA-256 diary.
WARNAllowed with an advisory note for your review.
ASKPaused in Approvals until you approve once or deny. Destructive actions require typing an exact confirmation phrase.
DENYAction blocked immediately; the session can keep working on safe tasks.
LOCKSevere breach (for example reading SSH keys or touching a decoy). Session freezes until you click Unlock session.

Frequently asked questions

Why did Aegis lock my session?

Aegis escalates to LOCK when an agent tries to read credential stores (such as ~/.ssh or live API keys), triggers a Minotaur decoy tripwire, or loops aggressively against blocked rules. Agents cannot unlock themselves. Inspect the Decision diary on Guard, then click Unlock session once you have verified the cause.

How do I protect Claude Code, Cursor, or VS Code?

Open the Apps tab and flip the switch beside the app or MCP server you want protected. Aegis creates a timestamped backup copy before editing any settings file so you can revert cleanly anytime. Tekton MCP entries already enforce Aegis natively and are never double-wrapped.

What does Sync policy floor in the Tekton tab do?

It copies your local ~/.aegis/policy.json into Tekton's monotonic policy floor path. Tekton merges that floor monotonically: Aegis can only make Tekton stricter, never loosen Tekton's workspace or domain boundaries.

Does Aegis send my files or prompts to any cloud server?

No. Aegis runs 100% locally on loopback 127.0.0.1 with zero cloud calls, zero telemetry, zero AI tokens, and zero external CDN assets. Outbound live DNS lookups are disabled by default during gate evaluation.

Where are my settings and logs stored on disk?

Your protection rules live in ~/.aegis/policy.json and your tamper-evident SHA-256 diary lives in ~/.aegis/ledger.jsonl. Click Copy diagnostics above to copy exact file paths and health status without exposing any secrets.
