# Aegis CEH v9 Knowledge Packs

**Source class:** FOUNDATIONAL_LEGACY_SECURITY_SOURCE  
**Primary source:** *CEH v9 — Certified Ethical Hacker Version 9 Study Guide*, Sean-Philip Oriyano, Sybex/Wiley, 2016.  
**Authority:** REFERENCE_ONLY. Current OWASP/agentic/API/MCP guidance and inspectable OTHRYS evidence take precedence.

## Purpose
These packs harvest durable security concepts from CEH v9 into Aegis without treating 2016-era tools, protocols, algorithms, or product recommendations as current implementation truth.

## Harvest law
- Preserve concepts, methodology and defensive lessons.
- Revalidate technical implementation details before use.
- Never convert legacy offensive examples into uncontrolled production actions.
- Candidate attacks belong in authorized Aegis Dojo/Tartarus test environments.
- Every learned control must eventually be tied to evidence, a test, or an explicit GAP state.
